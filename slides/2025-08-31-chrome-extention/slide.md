# 基本的な構成要素

---

## manifest.json の重要性

```json
{
  "manifest_version": 3,
  "name": "My Extension",
  "version": "1.0",
  "permissions": ["activeTab"],
  "action": {
    "default_popup": "popup.html"
  },
  "content_scripts": [{
    "matches": ["<all_urls>"],
    "js": ["content.js"]
  }]
}
```

<!-- 
スピーカーノート:
- manifest.jsonは拡張機能の設計書
- permissions は最小限に（セキュリティ重要）
- Manifest V3が最新版であることを強調
- 各フィールドの意味を簡潔に説明
-->

# 重要な注意点

---

<!-- _class: strategy-grid -->

## 開発時の重要ポイント

### セキュリティ重視
- **最小権限の原則**: 必要最小限のpermission
- **CSP対応**: Content Security Policy準拠
- **XSS対策**: ユーザー入力の適切な処理

### パフォーマンス考慮
- **メモリ使用量**: バックグラウンド処理の最適化
- **実行速度**: 重い処理は分割実行
- **ネットワーク**: APIコール回数の制限

<!-- 
スピーカーノート:
- セキュリティは最優先事項
- ユーザーのブラウザに負荷をかけない設計
- Googleの審査基準が厳格化していることも触れる
- これらの点を守らないと公開できない
-->
